# components/forms

ProjectWizard (client component): asistente de 3 pasos (datos de contacto, tipo de proyecto,
presupuesto/urgencia) usado embebido en `/contacto` y también dentro del modal de
`ProjectWizardButton`. Ver `Docs/BACKEND.md` sección 4 para el flujo completo
(server action → Zod → Supabase → Resend) y `Docs/FRONTEND.md` sección 5 para el diseño.
